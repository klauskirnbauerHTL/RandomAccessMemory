# Random Access Memory 🎲💾

> Who remembers last lesson?

Ein verspielter Zufallsgenerator, um Schülerinnen und Schüler für die Stundenwiederholung auszuwählen. Gebaut für den IT-Unterricht.

**Live:** https://klauskirnbauerHTL.github.io/RandomAccessMemory/

## Modi
- 💿 **Spin the Disk**: Glücksrad
- 🎰 **Jackpot.exe**: Slotmachine
- 👾 **Garbage Collector**: Ein Monster frisst einen Namen

## Features
- Mehrere Klassen, Namen per Copy & Paste hinzufügen
- **WebUntis-Import**: CSV-Schülerliste aus WebUntis (nur Langname, Vorname und Klasse werden übernommen, Klassen werden automatisch angelegt)
- Abwesende markieren, „Keine Wiederholung, bis alle dran waren“
- Im Browser erzeugte Chiptune-Musik und Soundeffekte
- Daten bleiben lokal im Browser (localStorage), Backup per JSON-Export/Import
- Leertaste zum Ziehen, Beamer- und Vollbild-Modus
